# Bowl Arena of Jacksonville

A portable static version of the Bowl Arena website concept. It reproduces the published one-page design without requiring ChatGPT Sites, React, Node.js, or a database.

## Files

- `index.html` — website content and structure
- `styles.css` — all visual styling and responsive behavior
- `assets/` — logo, hero photo, and snack-bar menu image

## Preview locally

Open `index.html` in a browser. For a local web server, run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

The project can be deployed as a static site through GitHub Pages, Cloudflare Pages, Netlify, Vercel, or conventional web hosting. No build command is required; publish the repository root.

## Before production use

Confirm all hours, prices, menu items, photographs, logos, and business claims with Bowl Arena management. Obtain permission to use business-owned branding and images before presenting the site as official.
